# 路线图

## 阶段划分

| 期 | 内容 | 产出 | 估时 |
|---|---|---|---|
| **P0** | 设计（当前） | `docs/DESIGN.md` `docs/ADAPTERS.md` | ✅ 进行中 |
| **P1** | 核心骨架 | 关系度 + 门控 + L1 索引 + 向量检索 + HTTP API + 召回 | 3~4 天 |

## 之后（独立项目）

### QQ Bridge 重写

现有 `qq-bridge` 的记忆是内嵌的（`state/social-v2.json`），会重写成：

```
qq-bridge（协议层 + 收发 + 频率控制）
   └─ 调用 mnema（记忆层）
```

要点：

1. 保留协议层（SnowLuma、消息编辑、限流、审计）
2. 记忆相关全部改为 HTTP 调用 mnema
3. 唤醒提示词的记忆段落用 `/v1/recall` 的 `rendered`
4. 角色卡迁到 mnema 的 persona（性格可编辑）
5. 叙事只读展示

> 这是**另一个项目**，本文档只留接口约定（见 ADAPTERS 第 9 节）。
