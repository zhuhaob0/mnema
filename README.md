# mnema

> 一个**仿人类记忆引擎**：为长期运行的 AI 提供个体记忆、关系感知、遗忘与唤醒。
> 不是聊天记录数据库，而是"一个会记事、会忘事、会想起、会因为关系远近改变记多少"的记忆系统。

---

## 这是什么

绝大多数 AI 应用把"记忆"做成检索一段对话历史。但人的记忆不是这样的：

- 人是**个体记忆**——不管和多少人聊过，记忆都属于同一个人
- 人会**遗忘**——但不是删除，是"想不起来"
- 人**按关系分配注意力**——不熟的人说的事转头就忘，在意的人很久都记得
- 人**回忆是重建**——每次想起都在重新拼装，细节会变
- 人会**巩固**——睡眠中海马体把当天的经历重放给皮层，慢慢抽象成知识

`mnema` 把这五件事做成了工程结构。

## 设计目标

| 目标 | 说明 |
|---|---|
| **个体记忆** | 一个实例对应一个"人"；所有对话共享同一份记忆 |
| **近似无限** | 索引永增（~200B/条），注入上下文永远是压缩后的几十条 |
| **会遗忘** | 权重衰减 + 沉底不可达；只有隐私/纠错才真删 |
| **会唤醒** | 多路召回（人物/时间/语义/情绪）+ 融合打分 + 重建 |
| **关系感知** | 每个联系人一个关系度，决定记什么、记多深、记多久 |
| **可接入** | 与应用解耦：HTTP/JSON API + Node/Python SDK + MCP server |

## 不做的事

- 不做神经元级仿生（STDP、脉冲网络）——LLM 权重不可控，收益极低
- 不做"无限原文存档"——原文归档只用于重建回忆，不进上下文
